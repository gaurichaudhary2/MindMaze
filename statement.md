# MindMaze – Project Statement

## Problem Statement

Most basic quiz applications provide questions at a fixed difficulty level and only display a final score.

MindMaze is designed to provide a more interactive reasoning assessment system where the challenge level can change according to the user's performance.

## Scope

The project focuses on a Java-based command-line reasoning assessment system with:

- Multiple puzzle categories
- Three difficulty levels
- Rule-based adaptive difficulty
- Level unlocking
- Score and accuracy calculation
- Category-wise performance analysis
- Assessment history
- Input validation

## Target Users

- Students
- Competitive examination learners
- Reasoning practice users

## Main Features

1. User setup and personalized session
2. Pattern Recognition challenges
3. Logical Reasoning challenges
4. Numerical Reasoning challenges
5. Mixed Challenge mode
6. Beginner, Intermediate and Advanced levels
7. Performance-based level unlocking
8. Rule-based adaptive difficulty
9. Score and accuracy calculation
10. Category-wise performance analysis
11. Assessment history
12. Input validation and error handling

## Project Goal

The goal of MindMaze is to demonstrate how Java programming and object-oriented design can be used to build a modular and interactive reasoning assessment system.
